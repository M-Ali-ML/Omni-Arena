API

Base URL http://localhost:3001. JSON bodies. The web dev server proxies /api and /health.

POST/api/arena/chat

Starts a blind matchup, or continues one from its latest winning response, and streams both responses over one SSE connection.

{ "prompt": "Explain JWTs in simple terms",
  "sessionId": "anon_123",
  "conversationId": "optional UUID from matchup_started" }
SSE eventPayloadNotes
matchup_started{ matchupId, matchupToken, conversationId, turnIndex, slots }First event. Save the conversation ID; no model identities.
token{ slot, token }Interleaved tokens for A and B
slot_error{ slot, message }Other slot keeps streaming
slot_done{ slot }Content/latency stripped from public event
matchup_done{ }Stream closes
Linear history: omit conversationId at turn 0. After a decisive left/right vote, resend it for a follow-up. The server reconstructs history from stored winners; ties, both-bad, skips, and unvoted turns cannot continue.
StatusPre-stream error
400Invalid body
403Conversation belongs to a different anonymous session
404Unknown conversation
409No decisive winner yet, or the conversation already advanced

GET/api/arena/leaderboard

{ "models": [ { "id", "displayName", "wins": 12, "losses": 8, "ties": 3,
                "skips": 1, "totalVotes": 24, "winRate": 0.5217,
                "rating": 1184.3, "ratingStdError": 41.7,
                "confidenceInterval": { "lower": 1102.6, "upper": 1266.0 },
                "componentId": 0 } ] }
winRate = wins / (wins + losses + ties) — skips excluded; win-rate fields are always present. Ordered by rating (nulls last), then wins.
Rating fieldMeaning
ratingBradley-Terry rating, Elo-like scale 1000 + (400/ln10)·r
ratingStdErrorStandard error (same scale)
confidenceInterval95% CI { lower, upper } from Fisher information
componentIdConnected component; ratings only comparable within a component
All four rating fields are null until the Python rating worker (worker/) has rated the model — clients treat them as optional and fall back to winRate.
