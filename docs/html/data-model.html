Architecture · API · Data model · Setup

Data model

PostgreSQL owns all arena state. SQL migrations in server/src/db/migrations/ apply in filename order, tracked in schema_migrations.

Tables at a glance

models
catalog of comparable models; only enabled ones enter matchmaking
matchups
one blind head-to-head per prompt; randomized slot assignment + token hash
responses
one row per slot per matchup: content, latency, error
preferences
one vote per matchup (unique constraint), winner nullable
schema_migrations
migration bookkeeping: name + applied_at

Vote semantics

left → slot A wins right → slot B wins both_good → tie both_bad → tie skip → excluded from winRate
Leaderboard: winRate = wins / (wins + losses + ties), computed by SQL aggregation in PostgresRepository.getLeaderboard(); 0 when a model has no votes.
