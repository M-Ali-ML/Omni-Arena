OmniArena

Blind side-by-side LLM comparisons — architecture, API, integration, ratings, and the React SDK.

Architecture

System overview: hexagonal ports, the protocol-adapter layer, the WebSocket control plane, multi-turn history, and the rating worker.
API

Chat, vote, leaderboard, analytics, the OpenAI-compatible model list, and WebSocket control — routes, events, and protocol selection.
Integration

Five wire protocols (SSE, AG-UI, A2UI, Vercel AI, OpenAI), which of them accept their own request body, slot join for compare views, and the real third-party integrations.
Rating methodology

Bradley-Terry / Rao-Kupper fit, Fisher CIs, style control, anomaly screening, rating history — and what the engine cannot rate.
Data model

Postgres tables and migrations for matchups, votes, ratings, rating history, and style-controlled scores.
Setup

Docker one-command self-host, the npm development path, environment variables, trigger modes, and the key-free mock provider.
SDK

@omni-arena/react — headless React-free primitives plus hooks for chat, voting, the leaderboard, and analytics.
